## 🌟 Visão Geral

Plataforma web para centro de estética e bem-estar animal — catálogo de banho & tosa, agendamento ágil e experiência mobile-first.

O projeto foi construído priorizando performance, manutenibilidade de código, design system consistente e padrões modernos de engenharia de software.

---

## 🚀 Principais Funcionalidades

- **Catálogo**: Catálogo visual de serviços de estética, bem-estar e cuidados especiais
- **Fluxo**: Fluxo rápido de pré-agendamento de horários com seleção de porte
- **Área**: Área de depoimentos de clientes e galeria de fotos de pets
- **Botão**: Botão flutuante integrado ao atendimento do WhatsApp
- **Design**: Design responsivo com pontuação máxima no Google Lighthouse

---

## 🛠️ Stack Tecnológica

O ecossistema do projeto é composto por tecnologias modernas e consolidadas:

- **Tecnologias Core**: `Next.js 15` `React 19` `Tailwind CSS` `Lucide React`
- **Estilização & UI**: Tailwind CSS, Radix UI primitives e Lucide Icons
- **Qualidade & Testes**: Linting estrito, Typecheck rigoroso e suítes automatizadas

## ⚡ Como Rodar Localmente

### Pré-requisitos
- Node.js (versão 20 LTS ou superior)
- Gerenciador de pacotes `npm`, `yarn` ou `pnpm`

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/BarujaFe1/cidade-pet-spa.git
cd cidade-pet-spa
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) (ou a porta informada no terminal) no seu navegador.
